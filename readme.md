# PDF Hash Comparator

Графічна програма на Python для порівняння двох PDF-файлів сторінка за сторінкою за допомогою perceptual hash.

Програма створена для перевірки PDF-газеток, каталогів та інших багатосторінкових документів. Вона дозволяє швидко знайти сторінки, які візуально відрізняються між двома файлами.

## Можливості

* вибір двох PDF-файлів через графічний інтерфейс;
* порівняння кожної сторінки PDF за perceptual hash;
* відображення hash distance для кожної сторінки;
* підсвітка результатів кольорами;
* виявлення сторінок, яких немає в одному з PDF;
* progress bar під час обробки;
* відображення поточної сторінки, яка обробляється;
* прев’ю відповідних сторінок двох PDF поруч;
* обробка PDF у фоновому потоці без зависання інтерфейсу.

## Як працює порівняння

Для кожної сторінки програма виконує такі дії:

1. Відкриває сторінку PDF за допомогою PyMuPDF.
2. Перетворює сторінку на зображення.
3. Перетворює зображення у формат RGB.
4. Обчислює perceptual hash за допомогою `imagehash.phash`.
5. Порівнює хеші відповідних сторінок двох PDF.
6. Обчислює hash distance.

Поточний поріг порівняння:

```python
THRESHOLD = 6
```

Результат вважається успішним, якщо:

```text
distance <= 6
```

Якщо:

```text
distance > 6
```

сторінка позначається як така, що відрізняється.

## Значення статусів

| Статус             | Опис                                          |
| ------------------ | --------------------------------------------- |
| `OK`               | Hash distance не перевищує встановлений поріг |
| `DIFFERENT`        | Hash distance більший за встановлений поріг   |
| `Відсутня в PDF 1` | Відповідної сторінки немає у першому PDF      |
| `Відсутня в PDF 2` | Відповідної сторінки немає у другому PDF      |

## Кольори в таблиці

* зелений — сторінки збігаються;
* червоний — сторінки відрізняються;
* жовтий — сторінка відсутня в одному з PDF.

Під час обробки великих PDF програма зберігає відрендерені сторінки в оперативній пам’яті для подальшого показу прев’ю.

## Встановлення

Клонуйте або завантажте проєкт, після чого відкрийте термінал у папці зі скриптом.
Встановіть залежності:

```bash
pip install pymupdf pillow imagehash
```

## Запуск програми

```bash
python pdf-diff.py
```

## Використання

1. Запустіть програму.
2. Натисніть кнопку **«Вибрати PDF 1»**.
3. Виберіть перший PDF-файл.
4. Натисніть кнопку **«Вибрати PDF 2»**.
5. Виберіть другий PDF-файл.
6. Натисніть кнопку **«Порівняти»**.
7. Дочекайтеся завершення обробки.
8. Перегляньте результати у таблиці.
9. Натисніть на потрібний рядок, щоб побачити прев’ю сторінок поруч.

Під час обробки progress bar показує загальний прогрес, а текстовий статус — поточний файл і номер сторінки.

Приклад:

```text
Обробка PDF 1: сторінка 25/80 | 25/160
```

## Обмеження

* Сторінки порівнюються за однаковими номерами.
* Якщо порядок сторінок змінився, програма не шукає відповідну сторінку в іншій частині документа.
* Незначні зміни рендерингу можуть впливати на hash distance.
* Дуже великі PDF можуть використовувати значний обсяг оперативної пам’яті.
* Захищені паролем або пошкоджені PDF можуть не відкритися.
* Програма не порівнює текстові об’єкти PDF безпосередньо — порівняння виконується за зображенням сторінки.
