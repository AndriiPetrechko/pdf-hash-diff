# PDF Hash Comparator

## Release v0.5.0

Графічна програма на Python для візуального порівняння **двох або трьох PDF-файлів** сторінка за сторінкою за допомогою perceptual hash (pHash).

Призначена для перевірки PDF-газеток, каталогів та інших багатосторінкових документів. Допомагає знайти сторінки та ділянки сторінок, які візуально відрізняються.

## Можливості

- Перемикання режиму порівняння **2 PDF / 3 PDF** у верхній панелі.
- Вибір рівно 2 або 3 PDF-файлів за один раз відповідно до режиму.
- Автоматичне відображення двох або трьох панелей прев’ю.
- Попарне порівняння: `1↔2` у режимі 2 PDF; `1↔2`, `1↔3`, `2↔3` у режимі 3 PDF.
- Поділ кожної сторінки на сітку **5 × 5** (25 блоків) і порівняння pHash кожного блоку.
- Підсвічування змінених блоків червоними рамками та можливість показати/приховати сітку.
- Таблиця результатів зі статусом, кількістю змінених блоків, максимальною та сумарною hash distance, деталями за парами PDF.
- Виявлення сторінок, відсутніх у будь-якому з вибраних PDF.
- Масштабування кнопками `+` / `−`, через `Ctrl + колесо`, а також `Fit page` і `Fit width`.
- Перетягування прев’ю мишею та опціональна синхронна прокрутка панелей.
- Індикатор прогресу, можливість скасування та обробка у фоновому потоці.

## Як працює порівняння

1. Програма відкриває вибрані PDF через **PyMuPDF**.
2. Рендерить сторінки у RGB-зображення.
3. Масштабує зображення для обчислення хешів до `512 × 768`.
4. Розділяє кожну сторінку на 25 блоків (5 рядків × 5 стовпців).
5. Обчислює `imagehash.phash` для кожного блоку.
6. Порівнює відповідні блоки сторінок з однаковими номерами у всіх вибраних парах PDF.
7. Позначає блок зміненим, якщо **максимальна distance серед пар** перевищує поріг.

Налаштування у скрипті:

```python
GRID_ROWS = 5
GRID_COLS = 5
BLOCK_THRESHOLD = 6
MIN_CHANGED_BLOCKS = 1
```

Блок вважається зміненим, якщо `distance > 6`. Сторінка має статус `DIFFERENT`, якщо кількість змінених блоків становить щонайменше `MIN_CHANGED_BLOCKS` (за замовчуванням 1). Інакше статус — `OK`.

У режимі **3 PDF** достатньо відмінності в будь-якій із трьох пар, щоб блок потрапив до списку змінених. Підсвічування показує спільну множину змінених блоків на всіх панелях, а не окремі відмінності для кожного файлу.

## Значення статусів

| Статус | Опис |
| --- | --- |
| `OK` | Кількість блоків із distance понад поріг менша за `MIN_CHANGED_BLOCKS` |
| `DIFFERENT` | Знайдено достатньо блоків із distance понад поріг |
| `Відсутня в PDF N` | Сторінки з таким номером немає в PDF N (може бути зазначено декілька файлів) |

**Кольори таблиці:** зелений — `OK`, червоний — `DIFFERENT`, жовтий — відсутня сторінка.

**Колонки таблиці:** номер сторінки; статус; змінено блоків (`N/25`); максимальна distance; сума distance; змінені блоки з деталями за парами (`1↔2` тощо). Сума distance охоплює всі блоки всіх порівнюваних пар.

## Встановлення

Потрібен Python із підтримкою Tkinter. Встановіть залежності:

```bash
pip install pymupdf pillow imagehash
```

Або, якщо у проєкті є `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Запуск програми

```bash
python pdf-diff-modes.py
```

Якщо ви перейменували файл скрипту на `pdf-diff.py`, використовуйте відповідну назву в команді.

## Використання

1. Запустіть програму.
2. У полі **«Режим»** виберіть `2` або `3` (за замовчуванням `3`).
3. Натисніть **«Вибрати PDF (2 файли)»** або **«Вибрати PDF (3 файли)»**.
4. У діалозі виберіть **рівно потрібну кількість файлів за один раз** (для множинного вибору можна використовувати `Ctrl`).
5. Натисніть **«Порівняти»** та дочекайтеся завершення.
6. Перегляньте кольорові статуси й показники в таблиці.
7. Натисніть на рядок сторінки, щоб побачити відповідні сторінки поруч. За потреби змініть масштаб, увімкніть або вимкніть сітку чи синхронну прокрутку.

При зміні режиму вибрані файли та попередні результати очищаються. Перемикання режиму недоступне під час порівняння.

Під час роботи progress bar відображає загальну кількість виконаних кроків, а текстовий статус — поточний PDF, сторінку або етап порівняння.

## Обмеження

- Сторінки зіставляються **лише за однаковими номерами**; пошуку переставлених сторінок немає.
- Якщо сторінка відсутня хоча б в одному PDF, вона отримує статус відсутності; для неї не виконується часткове порівняння решти файлів.
- pHash порівнює візуальне представлення, а не текстові об’єкти PDF. Незначні зміни рендерингу можуть впливати на результат.
- Сітка 5 × 5 визначає точність локалізації відмінностей: дрібні зміни можуть бути непомітними.
- Відрендерені сторінки зберігаються в оперативній пам’яті, тому великі PDF можуть потребувати багато RAM.
- Захищені паролем або пошкоджені PDF можуть не відкритися.
